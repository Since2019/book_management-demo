# 随手贴

Windows 文字和图片剪贴板浮窗，无需安装额外运行环境。

1. 双击 `启动剪贴板.cmd`。
2. 正常复制文字、网页图片，或使用截图工具复制截图，浮窗会自动记录。也支持在文件夹中选中 PNG、JPG、BMP、GIF、TIFF 图片文件后按 Ctrl+C，可一次复制多张。
3. 点击浮窗中的文字或图片，再按 **Ctrl+V** 粘贴到原来的输入位置。浮窗点击不会抢走原窗口的输入焦点。

窗口始终置顶，可拖动标题栏移动，也可调整大小。支持“全部 / 文字 / 图片”筛选。

- **Ctrl+Shift+V**：显示或收起浮窗。如果快捷键已被其他软件占用，可点击系统托盘图标。
- **暂停 / 继续**：控制是否收集新的复制内容，已有记录仍可选择。
- **删除选中 / 清空历史**：删除保存的历史，系统当前剪贴板内容不变。
- 关闭窗口或点击“收起”后继续在后台记录。右键系统托盘图标 → **退出**，完全关闭。

最近 60 条记录自动保存在本机 `%LOCALAPPDATA%\ClipboardShelf\history.xml`，下次启动恢复，不上传网络。按条数或总大小上限自动淘汰最旧记录（单条 8 MB，总计 48 MB；图片不超过 2400 万像素）。文字按纯文本保存，图片保留 PNG 和位图格式；图片文件会转换为可粘贴的图片；不收集其他文件、文件夹或富文本排版。仅收集工具运行后新复制的内容，不自动读取启动前的剪贴板。

历史文件为未加密的本地文件；复制不想留在历史中的内容前可暂停记录。选择旧记录会替换系统当前剪贴板，随后其他软件的 Ctrl+V 就使用这条内容。图片能否粘贴取决于目标软件是否接受图片。

工具不自动设置开机启动。可把启动文件的快捷方式放入 Windows 的启动文件夹（Win+R 输入 `shell:startup`）按需启用。

开发验证：`powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\Start.ps1 -SelfTest`
